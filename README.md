# Crime Scene Analyzer

An AI-powered video surveillance analysis system built using Flask, YOLOv8, DeepSORT, and OpenCV.

## Features (Version 1)

- Video Upload
- Object Detection
- Multi Object Tracking
- Timeline Generation
- Analytics Dashboard

## Tech Stack

- Python
- Flask
- OpenCV
- YOLOv8
- DeepSORT
- SQLite

Project is under active development.
